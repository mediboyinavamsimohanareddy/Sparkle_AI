# Sparkle AI — Intelligent Workspace Platform

Sparkle AI is a modern, high-performance intelligent workspace platform featuring AI chat powered by Google Gemini, document analysis, code generation, voice input/output, workspace organization, and file management.

## Features
- **AI Workspace Chat**: Powered by Google Gemini API.
- **Document & Image Analysis**: Upload PDF, DOCX, TXT, CSV, PNG, JPG files.
- **Voice Assistant**: Integrated speech recognition and text-to-speech output.
- **Workspaces & Folders**: Categorize chats and organize files easily.
- **Modern UI**: Dark/Light themes, floating glass composer, and compact controls.

## Tech Stack
- **Frontend**: React (Vite), Lucide Icons, Axios, Tailwind/Custom CSS.
- **Backend**: Java 17, Spring Boot, Spring Data JPA, H2 Database.
- **AI Gateway**: Google Gemini REST API.
