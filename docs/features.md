# NovaAI Features Overview

1. **Multi-Model AI Chat Workspace**
   - Context-aware multi-turn conversations
   - AI Modes: General, Coding, Study, Writing, Document Analysis, Brainstorming
   - Streaming-style message loading effect with copy/edit/regenerate capabilities

2. **Smart Document & Image Assistant**
   - PDF, DOCX, TXT, CSV, XLSX text extraction & summarization
   - Vision & Image analysis support (PNG, JPG, WEBP)
   - Integrated preview in chat input & chat bubbles

3. **Workspaces & Hierarchical Folders**
   - Tree navigation for organizing projects, college work, personal notes
   - Drag/move conversations and files across folders

4. **Global Search & Shortcuts**
   - Global search modal with `Ctrl + K` hotkey support
   - Instant query matching across chat titles, messages, file names

5. **Futuristic Responsive UI**
   - Dual theme support (Dark / Light) with local state persistence
   - Collapsible & mobile-responsive drawer sidebar
   - Syntax-highlighted code blocks with 1-click copy
